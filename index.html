1 Before you begin — set up Graph Explorer

Complete these steps before generating the query JSON below, so Graph Explorer is ready to receive it. Switching from GET to POST clears the request body, so set up the window first.
  1. 1 Open Graph Explorer and sign in with your NIH account.
  2. 2 Change the method dropdown from GET to POST.
  3. 3 Set the URL to: https://graph.microsoft.com/v1.0/search/microsoft.graph.query
Graph Explorer is now ready. Generate the query JSON below, then copy and paste it into the Request body tab.

Paste or upload Graph API response

In Graph Explorer:

1. Click the Request body tab and paste the query JSON copied from Tab 1.
2. Click Run query.
3. In the response panel, click Response preview, press Ctrl+A then Ctrl+C to copy.
4. Paste into the box below and click Process results.

⚠️ If the response shows your user profile instead of search results, the method is still set to GET or the URL was not updated — go back to Tab 1 and repeat the setup steps.
